# Vintage Marketplace

A modern web-based used-goods marketplace designed for local communities in Ethiopia.

## Technology

Frontend:
- React
- Vite
- TypeScript
- Tailwind CSS

Backend:
- Node.js
- Express
- TypeScript

Database:
- PostgreSQL

## Project Structure

frontend/
backend/
docs/

## Development

Frontend:
npm install
npm run dev

Backend:
npm install
npm run dev
